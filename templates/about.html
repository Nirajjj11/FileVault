About FileVault

FileVault is a web-based file management platform designed to help users securely organize, manage, store, and share their digital files from a single place.

📁 What is FileVault?

FileVault provides a simple and organized environment for managing personal files and folders. Users can create folders, create nested folders, upload files, rename files and folders, download files, and delete their own content.

🎯 Our Purpose

The purpose of FileVault is to demonstrate how a practical file-management system can be developed using Django's Model-View-Template architecture, authentication, authorization, forms, database relationships, and file handling.

Authentication & Authorization

FileVault uses Django's authentication system and ownership-based authorization to protect user resources. File and folder operations are restricted to the authenticated owner, helping prevent users from managing another user's content.

⚙️ How FileVault Works

FileVault follows Django's Model-View-Template (MVT) architecture. A typical request travels through the application in the following way:

Browser → URL → CBV → Form / Model → Database → Template

Project Modules

👤 Accounts

Handles user registration, login, logout, authentication, and account-related functionality.

📁 Storage

Handles folders, nested folders, file uploads, file management, and storage-related operations.

🔗 Sharing

Provides the foundation for controlled folder and file sharing functionality.
